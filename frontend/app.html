Get demo tokens

DMOA/DMOB are this testnet's stand-in for a second real asset (see the footer) — minting them is normally owner-only, so this faucet is what actually lets a new wallet try the deposit flow below. One claim gives 1,000 of each, once per wallet per day. You'll also need a little real testnet MON for gas — get that free at faucet.monad.xyz first (needs a quick human check there, so it isn't automatable from here).

Deposit into a vault

Both steps sign from your wallet. The priced deposit (depositWithPriceUpdate) needs a fresh Pyth price pushed in the same transaction — a serverless function fetches that (it holds the Hermes API key so your browser never has to), then your wallet signs the actual deposit.

Reads use the public RPC https://testnet-rpc.monad.xyz and need no wallet — pool price is read straight from each vault's own Uniswap v3 pool via its public slot0(), no indexer or oracle round-trip needed for price itself. Writes go through window.ethereum on chain 10143. AUSD here is a separate stablecoin, not affiliated with Aurora.
